# TempoRAC 实验计划（temporac.execution.v4）

> **前瞻性、零实证结论、same-family provisional。**
>
> 本文件只规划证据与停止条件，不授权实现、数据读取、服务器连接、训练启动、评测能力申请、论文修改或任何 Git 操作。当前 `launch authorization = 0`。旧 WARP-PHASE 计划、执行合同、环境候选、磁盘预算、服务器预检和运行状态均不继承。

**问题：** 在外部提供的 person-indexed pose tracks 上，identity-indexed window-local relative-tempo routing 是否能在同一身份轨迹发生节奏漂移时，借助共享 slow/medium/fast response experts 改善每人重复计数，同时保持一条连续响应并对每个身份只解码一次？

**方法论断：** detached irregular-clock cue 只改变三个 matched shared experts 的 window-local soft routing；概率级融合经 exact positive NOLA 重建后，以固定阈值 0.5 的 connected-component decoder 对每个身份调用一次。

**日期：** 2026-08-16  
**唯一规范合同：** `refine-logs/FINAL_PROPOSAL.md`，其内容必须与 `refine-logs/temporac/FINAL_PROPOSAL.md` byte-identical，规范 SHA-256 为 `562325dedab0637421f62dec5ad149b3c884f67b47c4b525c8fb54a57bb1233c`。  
**审查上限：** GPT-5.6-Sol / OpenAI same-family / provisional。  
**计划硬上限：** 1 个主张、4 个实验块、3 个 baseline families、27 个训练 job、93 A6000h、最大并发 2。

## 5. 实验块

### B1：实现与有效性前置（非论文主张）

- **Claim tested：** C1/S1 的证据是否来自合同规定的同一个系统与 primitive unit。
- **Why：** 在任何训练成本或 evaluator 能力之前排除实现漂移、label leakage、NOLA/decoder 错误、跨身份污染和资源不匹配。
- **Dataset/split/task：** P0--P3 与 S0 只使用代码、纯合成 fixtures 和去敏 schema；S1 后才允许经独立授权读取 v44 train/val。
- **Compared systems：** 无 efficacy comparator；只做 contract conformance。
- **Decisive checks：** seven invariants；40-row X0 manifest；13-row topology bank；10,368-row operator bank；fused-only gradient；positive NOLA；pre-gap reset；two-identity untouched-output；blocked=uniform；archive/receipt canonical bytes；forbidden-key/import/path firewall。
- **Success criterion：** P0--P3、S0、G0/K0、G1/K1、G2/K2、G4/K5/K6 全部 PASS，且 receipt hashes 完整可复算。
- **Failure interpretation：** 证据无效；全局停止，不进入或不继续训练/评测。
- **Paper target：** 附录审计表；正文只在 B4 汇总必要 validity 数字。
- **Priority：** MUST-RUN prerequisite。

### B2：Natural local routing 与 clean retention

- **Claim tested：** C1。
- **Why：** 唯一自然数据 efficacy decision，直接回答 anchored bottleneck。
- **Dataset/split/task：** 训练只用 count-blind certified v44 train；冻结后在全部 134 个 v44 val identities 上生成 paired `natural-clean`/`natural-drift` predictions，所有 abstention 以 zero estimate 纳入；video=`opaque_key_hex` equality class，component-cluster bootstrap。
- **Compared systems：** local canonical 对 strongest of global NUDFT / uniform / capacity-control；同一 drift draw 内重选 strongest arm，并将同一 arm 用于 paired clean。
- **Metrics：** primary 为 video-first、三 seed 平均的 NAE 差值 `M_route` 及 relative improvement；clean 为 `D_clean` 和 ratio rule；OBO 只描述，不作决策。
- **Setup：** seeds `20260815,20260816,20260817`；固定 10,000 component-bootstrap draws；134/9 val identity/component frozen population；stub-inclusive artifact cardinality 9,648。
- **Success criterion：** 完整满足合同 K7 point/CI AND clean-retention rules，且 G5a/G5b capability chain 完整。
- **Failure interpretation：** TempoRAC 唯一主张失败；结束路线，无 rerun、retune、过滤或 fallback。
- **Paper target：** 主表：local 与 frozen strongest comparator 的 drift NAE、relative gain、paired CI、clean delta/upper bound；OBO 作为次要列。
- **Priority：** MUST-RUN，但仅在 K6 后冻结自然 artifacts，并在一次性 evaluator capability 内运行 G5b→K7。

### B3：三乘三 expert specialization

- **Claim tested：** S1。
- **Why：** 证明 slow/medium/fast branches 不是装饰性复制，且 local routing 的相对节奏机制可解释。
- **Dataset/split/task：** 合同 U0032--U0039 fixed synthetic evaluation source orbits；PCHIP/sinc；七个 blocks、十 traversals、三 response seeds、offset zero。
- **Compared systems：** 三个 matched branch responses 按三列 soft analytic responsibility 比较；不引入新训练 job。
- **Metrics：** `H_s,k,j`、aggregate `H_k,j`、`G_diag`、每列 responsibility fraction；10,000 source-orbit bootstrap draws。
- **Success criterion：** K4 的 per-seed、aggregate、lower-bound 和 support 条件全部通过。
- **Failure interpretation：** 支持性机制不成立，且因其是 success condition，TempoRAC 全局停止；不得只保留 B2。
- **Paper target：** 一张 3×3 matrix + `G_diag`。
- **Priority：** MUST-RUN。

### B4：Degree-one certificate、resampler 与 one-decode 边界

- **Claim tested：** C1 的 primitive-unit、simplicity 和 decoder validity anti-claims。
- **Why：** 排除一个物理重复被 phase winding 或 window overlap split/merge，以及用更复杂 decoder 才能成立的解释。
- **Dataset/split/task：** 纯合成 X0/topology/operator fixtures、U0032--U0039 fixed synthetic evaluation physical strata、所有 32 offsets；自然 val 只在 K7 vault 内作每 interval 一 pulse 的最终 primitive-unit kill。
- **Compared systems：** analytic vs certified pulses；linear/PCHIP/sinc pullback；fixed component decoder；无 alternate decoder。
- **Metrics：** certificate coverage；pulse bit/count equality；phase error `<=0.02` cycles；`B_err=0`；positive/negative margins each `>=0.10`；K7 每 evaluator interval 恰一 pulse、union 外零 pulse。
- **Success criterion：** G1/K1/G4/K5/K6 与 K7 primitive-unit checks 全部通过。
- **Failure interpretation：** one-decode counting 或 human primitive-unit binding 不可信；停止，不替换 integral/NMS/period-fit decoder。
- **Paper target：** 一张紧凑 validity 表；详细 fixture inventory 仅附录。
- **Priority：** MUST-RUN。

## 11. 数据、隐私与 split firewall

- **允许自然输入：** 仅 v44 train/val 两个已冻结 source pickle；进入 learner 前必须由 trusted packer 拆为 feature-only archives 与 separately permissioned evaluator vault。
- **learner whitelist：** `motion`、`person_mask`、`frame_mask`、`sampled_frame_indices`、`source_length`、opaque key、local slot；key/slot 只路由，不作 tensor。
- **deny before deserialization：** `count_gt`、`density_gt`、raw count/period/periodicity/bbox/boundary、object/person mappings、video/source identifiers、paths/provenance、association/coverage、evaluator metric/classification。
- **禁止路径类：** `data/test/**`、任何包含 historical test sources 的 v4x/v46 cache、`results/**`、`output/**`、以及 Pilot Audit 列出的 official-complete/selection/precommit tools。它们只能作为 denylist 字符串被静态扫描，不能被打开、hash、stat 或反序列化。
- **训练/选择：** teacher 只用 X0 train，teacher/response checkpoint 只用 X0 tune objective；response natural family只用 certified train features/teacher pseudo-targets；自然 val 仅用于冻结 certificate/prediction 和最终一次 evaluator decision。
- **capability：** G5a 前 evaluator vault 不可达；一次 capability 只允许一个 non-resumable evaluator process 依次 G5b→K7；training credentials 与 optimizer entry points 必须不存在。

## 12. 风险与 mitigation

- **Implementation drift：** P0/P1 exact interface/import/hash checks；WARP objects package-isolated。
- **Strict certificate 造成空/低覆盖：** K1 使用已冻结 G0 denominators；失败即停止，不降低 coverage 或过滤。
- **Specialization 不成立：** K4 是 kill gate；不得把 S1 删除后保留 C1。
- **Decoder/resampler artifact：** 10,368 fixtures + all offsets + both resamplers + margins；失败不换 decoder。
- **Natural unit mismatch：** K7 每 raw interval 一 pulse，union 外零 pulse；单个 mismatch 全局杀死。
- **Label leakage：** physical split、import graph、forbidden-key scan、G5a capability boundary和 receipt roots共同约束。
- **Compute/disk pressure：** fixed 93h ledger、64 GiB output cap、kill-only release；不动用 7h margin或删除证据自救。
- **Review independence/novelty：** 所有语义审查仍为 same-family provisional；本计划不授予 novelty、title、venue、paper 或 public claim。

当前 execution blockers 完整且仅为：本计划尚未获得独立执行授权；fresh TempoRAC preflight 尚未产生；trusted-packer grant 尚未授予；exact runtime/environment lock 尚未提交；one-use evaluator capability 尚未授予。它们不是方法 blocker，且任何一个都不能由旧 WARP 记录、现有服务器快照或本计划文字代替。
