\section{Planned Experiments and Analysis}
\label{sec:experiments}

The protocol is planned but is neither frozen nor executed for the proposed
multi-person system. Existing single-person development artifacts are excluded
from every table because they neither implement the proposed method nor use the
target benchmark. Result prose will be enabled only after a frozen collaborator
bundle passes experiment and claim audits.

\subsection{Protocol and metrics}
The result manifest must bind the MultiRep release, official split, video and
annotation checksums, evaluator revision, preprocessing fingerprint, pose
modality, supervision path, hardware, seeds, configuration, and raw logs. We
separate three protocols: oracle tracks, tracks from one frozen common frontend,
and each method's native pipeline. Native rows provide context but cannot form
a matched ranking against common-track rows. Predicted-track evaluations retain
HOTA \cite{luiten2021hota}, IDF1, and identity switches
\cite{ristani2016idmetrics} as frontend diagnostics, separate from the counting
metrics. Their proposed-method values remain \R{ours-hota}, \R{ours-idf1}, and
\R{ours-idsw}, respectively, until the same frozen bundle binds them.
For every predicted-track protocol, the manifest must also freeze tracklet
creation, reset, re-entry, fragmentation, merge, retirement, and reconciliation
rules, plus the assignment from predicted tracklets to ground-truth people.
Until these semantics are source-bound, predicted-track count rows stay disabled.

The principal counting metrics are Period-mAP, Period-AP50, Period-AP75, AvgMAE,
and AvgOBO,
using the release-native MultiRep definitions \cite{tang2024multicounter,
tang2026multicounterplus}. The manifest must freeze the evaluation unit
(persistent ground-truth person or predicted tracklet), assignment cost,
unmatched-track rule, per-person/per-video aggregation, empty-support and
zero-count handling, exact formulas, and evaluator hash; no metric is enabled
until those semantics agree with the selected release.
Every reproduced learned method requires at least three named seeds frozen before
results are inspected; we will report the mean, sample standard deviation, and a paired video-cluster
bootstrap 95\% confidence interval. A published checkpoint may appear as a
contextual row, but it cannot support a variance estimate. Dataset and evaluator
fields remain \Protocol{multirep-release} and \Protocol{evaluator-revision}.
The frozen bundle must also contain per-person ground truth, per-person
predictions, track identifiers, evaluator outputs, and the exact commands that
produced each row. Checksums bind the structured source of every table cell, so
the manuscript cannot silently mix releases, frontends, or reruns.

\subsection{Main comparison}
Table~\ref{tab:main} separates native MultiCounter variants from matched oracle-
and predicted-track families. Oracle tracks isolate counting; the common frozen
frontend measures robustness to track errors. In each matched family, Track-PAMS
tests identity/window adaptation, track-global tempo tests local versus global
estimation, and the local router tests the full hypothesis. RepNet and TransRAC
\cite{dwibedi2020repnet,hu2022transrac}, PoseRAC
\cite{yao2025poserac}, dynamic-query counting \cite{ma2026detrc}, and
dual-branch spatiotemporal counting \cite{wang2026d2stx} enter this block only
if input, output, tracking, and evaluation parity can be demonstrated. No cell
will be emphasized across incompatible protocols. The table will be generated
from frozen structured results rather than manually transcribed values. A
baseline enters the common-track block only if its temporal input and output can
be adapted without privileged labels or method-specific tracking. When such
parity cannot be established, the method remains contextual and its unavailable
metrics are reported as not applicable rather than imputed.

\subsection{Mechanism ablation}
Table~\ref{tab:ablation} separates local ACF and Fourier evidence, local against
global tempo, single-expert and hard against soft routing, and boundary
reconstruction. ``Boxcar'' is unweighted response averaging on valid overlap;
``decode$\rightarrow$aggregate'' decodes every window and then reconciles its
events or counts under one frozen rule. A boundary-offset control moves one event
through all window phases. Every retained row must match parameter count, context,
frontend, training budget, paired videos, and seeds, and must point to one commit
and configuration. Removal rows for routing-consistency,
track-continuity, or fallback behavior will appear only if those components
exist in the frozen training graph. This rule prevents a writing placeholder
from becoming a simulated ablation. Each contrast will report the paired
video-cluster confidence interval as well as its seed aggregate, because an
unpaired comparison could confound the component change with video difficulty
or initialization. The primary outcome, contrast direction, bootstrap
replicates, multiplicity policy, and failure/exclusion rules must be frozen
before results are inspected.

\subsection{Nonstationary-tempo diagnostic}
Figure~\ref{fig:tempo-diagnostic} defines the planned mechanism test. A frozen
piecewise time-warp will change one person's pace while preserving the evaluation
unit and paired identity. The final plot will use either a selection-rule-bound
example or an aggregate fixed before inspection. It must record source data,
generator hash, warp schedule, routing entropy, reconstructed response, and
clean-to-corrupt metric change. Counts by number of people, occlusion level,
and identity-switch severity remain secondary diagnostics. The figure can
support a mechanism statement only after the paired artifact and its generation
trace pass audit.

Separate mask-leakage controls will hold motion fixed while applying periodic
and nonperiodic missingness, and will hold the mask fixed while changing tempo.
They test whether period confidence or routing succeeds by reading visibility
rather than motion. The generator, missingness schedules, minimum support, and
all exclusion rules must be frozen before any output is inspected.

The warp contract must map frames, masks, and event timestamps; freeze segment
boundaries, interpolation, output duration and support, and tempo-severity bins;
and pair the synthetic stress test with held-out natural nonstationarity. It
changes tempo inside a track without changing identity or source-event count.
Clean and warped samples therefore share an evaluation cluster, allowing paired
changes to isolate the intended stressor.
Occlusion and identity-switch stress tests are generated separately so that a
tempo conclusion is not attributed to a simultaneous perception failure. Any
representative visualization follows a frozen selection rule; otherwise, the
paper reports an aggregate to avoid post hoc example choice.
