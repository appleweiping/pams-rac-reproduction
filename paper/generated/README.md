# Generated evidence bindings

`evidence_values.tex` is generated only from a frozen, audited experiment
artifact manifest. It may declare values through `\DeclareResult`, protocol
fields through `\DeclareProtocolField`, prose claims through
`\DeclareResultClaim`, and exactly one abstract evidence sentence through
`\DeclareAbstractResult`.

This pre-results package intentionally does not contain that file. Hand-entered
numbers and claims are prohibited.
