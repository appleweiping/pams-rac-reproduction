# Acceptance-Contract Review — Round 1

**Decision:** revisions required

1. Make the evidence/delivery freeze immutable with clean-tree or manifest
   hashes and enumerate every freeze-bearing document.
2. Replace vague story/notation checks with machine-readable inventories and
   exact checker outputs; define missing (d) and (epsilon).
3. Define a component transition schema with digest-bound implementation
   anchors and PASS tests for every module and training term.
4. Extend the supervision firewall from count labels to count and period labels
   across all development and inference stages.
5. Resolve conflicting contribution maps and mark every experiment subsection
   with authoritative claim IDs.
6. Scan all submission-facing source, figures, supplement, generated content,
   and extracted PDF text; allow only explicit denials/prior-art statements.
7. Reconcile completed vector assets with the blocked figure contract and use
   one `visual_reference_only` vocabulary for PPT provenance.
8. Redesign the result manifest around per-method/protocol/run families, add
   missing disclosures, separate native/context rows, and include TransRAC plus
   the full common-interface baseline set.
9. Digest-bind every input/output artifact, define non-self-referential manifest
   integrity, cover figures and tables, and harmonize data formats.
10. Link distinct seeds, per-run metrics, aggregate statistics, paired video
    clusters, and official single-checkpoint exceptions per result family.
11. Make anonymity and final readiness executable, enumerate every mandatory
    same-freeze audit, and require the collaborator artifacts, official CVPR
    2027 kit, and healthy cross-family review.

All requirements were incorporated into contract version 2 for round-2 review.
